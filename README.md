# Setup Instructions:
1. Download the app project ZIP file
2. Extract the ZIP file
3. Open the extracted folder
4. Right click the "final_mobile_apps_project" folder and "Open with code (vs code)".
5. After opened the project file in vs code, open Terminal and type command "Flutter run"
6. You can start to play around the app now!
Note: No need to do anything else, Firebase / Backend is already connected to the Flutter Project
